- ✅ Provider registration — `register()` with stake, UI at `/provider/register`
- ✅ Provider staking — `stake()` / `unstake()` with auto-deactivation below `MIN_STAKE`; UI on `/provider/settings`

- ✅ Provider bidding — `JobAuction` with a 30 s window; provider nodes auto-bid via `StartProviderBidder`

- ✅ Escrow — the agent wallet funds `deposit()` for the selected provider before execution
- ✅ Payment settlement — `release()` after attestation, streamed to the UI with its tx link

### Phase 3 — Agent economy
- ✅ Autonomous agent wallet — `chain/wallet.go`, exposed at `GET /agent/wallet` (address, live MON balance, contract links)
- ✅ Agent-to-provider transactions — escrow funding and settlement signed by the agent, no human in the loop
- ✅ Agent-to-agent compute — `delegate_compute` tool publishes subtasks over Gensyn AXL and awaits a peer result (`agent/delegation.go`)
- ✅ Reputation — `recordJobCompleted()` on-chain after each successful session
- ✅ Provider scoring — reputation and slash history feed straight back into the next selection

### Phase 4 — Verification
- ✅ Merkle execution proof — per-action SHA-256 hashes, binary Merkle tree, per-action proofs at `/audit`
- ✅ On-chain attestation — `ExecutionAttestation.attest()` on Monad; only hashes go on-chain
- ✅ Dispute flow — `dispute()` / `resolveDispute()` on the contract, `POST /sessions/{id}/dispute`
- ✅ Slashing — `slashProvider()` and registry `slash()`, `POST /sessions/{id}/slash`, Merkle root committed as evidence

### Phase 5 — Demo polish
- ✅ One button — **Deploy my AI workload** at `/launch`, autopilot mode (`autopilot: true` skips the human approval gate)
- ✅ Ten-stage live pipeline driven by `stage` WebSocket events
- ✅ Every on-chain event carries a Monad transaction link — escrow, attestation, reputation, settlement
- ✅ Provider comparison table rendered live from the scoring stage
- ✅ Monad receipt panel collecting every transaction from the run
- ✅ Agent wallet strip showing the address, live MON balance and a faucet warning when unfunded
